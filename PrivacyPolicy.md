# Privacy Policy

Last Updated: June 20, 2026

## Introduction

This Privacy Policy explains how Zexn collects, uses, and stores information when you use it.

By using the bot, you agree to this Privacy Policy.

## Information We Collect

### Discord Data
- User IDs
- Server (Guild) IDs
- Channel IDs
- Message IDs (when required for commands)
- Role IDs

### Music Data
- Search queries used to play music
- Queue information
- Playlist data (if applicable)
- Server configuration

### Usage Data
- Command usage
- Error logs
- Performance metrics

## Information We Do Not Collect

We do not intentionally collect:
- Discord passwords
- Payment information
- Private messages unless required for a command
- Message content beyond what is necessary to execute commands

## How We Use Information

We use collected information to:
- Operate the bot
- Process music playback requests
- Maintain queues and playlists
- Improve reliability
- Prevent abuse
- Debug errors

## Data Storage

Most data is stored temporarily.

Persistent data may include:
- Saved playlists
- Server settings
- User preferences

## Data Sharing

We do not sell, rent, or trade your personal information.

Information may only be shared:
- When required by law
- To protect the security of the Bot
- With service providers necessary to operate the Bot

## Third-Party Services

The Bot may use third-party services, including:
- Discord API
- Music streaming or search providers
- Cloud hosting providers

These services have their own privacy policies.

## Data Retention

Temporary data is deleted automatically.

Configuration and playlist data may be retained until:
- Removed by the user
- The Bot leaves a server
- The service is discontinued

## Your Rights

You may request:
- Deletion of stored data
- Information about stored data
- Removal of server configuration

## Children's Privacy

Mochi can be used by all users, but if any users are below the required minimum age of discord, it may function differently.

## Security

We take reasonable measures to protect stored information but cannot guarantee absolute security.

## Changes

This Privacy Policy may change at any time. Continued use of the Bot indicates acceptance of the updated policy.
